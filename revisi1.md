# REDESIGN LANDING PAGE (ANTI AI SLOP)

## Tujuan

Landing page saat ini masih terasa seperti hasil AI Generator modern.

Target redesign bukan membuat website lebih "rame", tetapi membuatnya terlihat seperti website institusi profesional seperti:

- IKLA
- Universitas besar
- Company profile premium
- Website pendidikan kelas enterprise

Hasil akhir harus terasa dibuat oleh UI Designer, bukan AI Generator.

---

# GLOBAL RULE

JANGAN membuat section dengan pola seperti berikut.

[Badge kecil]
Judul
Deskripsi
Card

atau

Logo
Badge
Heading
Paragraph
Button

# YANG HARUS DIHINDARI

Jangan menggunakan pola desain AI berikut.

- Badge hijau kecil di semua section.
- Floating logo.
- Card tanpa fungsi.
- Gradient berlebihan.
- Shadow tebal.
- Border radius terlalu besar.
- Hero dengan badge + logo + heading.
- Section identik satu sama lain.
- Terlalu banyak icon dekoratif.
- Empty card.
- Glassmorphism berlebihan.
- Ornamen yang tidak memiliki fungsi visual.

---

# TARGET AKHIR

Saat landing page selesai, tampilannya harus memberikan kesan seperti website institusi pendidikan nasional yang dibuat oleh UI Designer profesional.

Inspirasi utama:

- IKLA
- Website universitas modern
- Company profile premium
- Bukan template AI Generator.

Seluruh komponen harus memiliki fungsi visual yang jelas, hierarchy typography yang kuat, spacing yang lega, serta konsistensi desain di setiap section.
